Common Automation Patterns

Most automations follow one of these proven patterns

Pattern 1 — Simplest

Trigger → Action

Trigger → Action

e.g. "When a form is submitted → send an email notification"

Pattern 2

Form → Database → Email

Form → DB → Email

e.g. "Leave request → logged in SharePoint → manager email"

Pattern 3

Scheduled → Fetch → Transform → Report

Schedule → Fetch → Transform → Report

e.g. "Monthly trigger → pull ERP data → format → send to leadership"

Pattern 4
